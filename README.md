# 面向企业服务的 Agent CLI

这是一个面向公众的项目介绍页面，介绍一种让工程师、自动化程序与 AI Agent 共用企业服务能力的 CLI 架构。

## 内容

- index.html：可直接部署的静态介绍页面
- agent-cli-public-introduction.pdf：适合下载和分享的 PDF 版本
- assets/：页面使用的 SVG 架构图
- source/figures/：架构图的 FigureSpec 源文件

## 架构概要

项目把企业服务能力整理成统一的命令契约，并让不同调用者共享同一个执行内核：

工程师 / 自动化程序 / AI Agent
              ↓
终端、Shell、进程调用或 MCP
              ↓
       共享 CLI 核心
              ↓
       任务编排与服务适配
              ↓
          企业服务

公开页面只描述架构抽象和使用边界，不包含内部服务名称、真实地址、组织标识、凭据格式、员工信息或可直接访问企业系统的示例。

## 本地预览

直接用浏览器打开 index.html 即可预览。页面是自包含静态 HTML，架构图已经以内联 SVG 形式写入页面。
